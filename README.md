# 🚀 Premium AI Product Manager Portfolio

A modern, fully responsive portfolio website for an AI Product Manager built with React, Tailwind CSS, and Framer Motion. Features smooth animations, dark mode support, and production-ready components.

## 🌟 Features

### Design & UX
- ✨ **Modern Premium Design** - Clean, minimal, SaaS-inspired aesthetic
- 🌓 **Dark/Light Mode** - Full theme support with system preference detection
- 📱 **Fully Responsive** - Perfect on mobile, tablet, and desktop
- ⚡ **Smooth Animations** - Framer Motion micro-interactions throughout
- 🎨 **AI-Inspired Aesthetics** - Gradient accents and modern UI patterns
- ♿ **Accessible** - WCAG compliant with proper semantic HTML

### Sections
1. **Hero Section** - Eye-catching intro with CTA buttons and animated backgrounds
2. **About Section** - Personal story, expertise highlights, and skill preview
3. **Experience Timeline** - Detailed career journey with expandable content
4. **Skills Matrix** - Categorized skills with proficiency levels
5. **Featured Projects** - 4 detailed case studies with modal deep-dives
6. **Testimonials** - Social proof from colleagues and managers
7. **Contact Section** - Contact form with social links
8. **Footer** - Navigation and social connections

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## 📝 Customization

Edit `src/constants/data.js` to update portfolio content:
- Hero section
- About section
- Experience
- Skills
- Projects
- Testimonials
- Contact info
